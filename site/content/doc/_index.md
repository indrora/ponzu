# Documentation

This section contains documentation for the Ponzu archive format and the `parc` reference implementation.

## Format Documentation

The Ponzu archive format is documented in two main sections:

- **[Introduction]({{< relref "intro" >}})** - Overview of the Ponzu format, design rationale, and comparison with tar
- **[Specification]({{< relref "spec" >}})** - Complete technical specification including record types, compression, metadata structures, and implementation details

## Reference Implementation

The `parc` utility is the reference implementation for creating and extracting Ponzu archives. It provides a command-line interface similar to traditional archive tools.

- **[parc manual pages]({{< relref "parc" >}})** - Complete documentation for the `parc` command-line utility
